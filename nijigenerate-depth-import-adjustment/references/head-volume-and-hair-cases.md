# 後頭部の必須確認と髪の有無による分岐

## 適用

頭部を持つキャラクターの自動リグでは後頭部を必ず評価する。顔だけが良好でも頭部の完了ではない。既存リグの頭部修正でも、頭頂・側頭・後頭・耳・うなじを一つの頭のつながりとして確認する。髪がないことは後頭部を省略する理由にならない。頭部自体がないデザインのみ理由付きで対象外にできる。無関係な限定修正に、頭部全体の再構築を追加する指示ではない。

まず実際の絵に、頭頂、側頭、耳の付け根、後頭部中央、うなじ、頭と首の支点を置く。顔面、頭皮、髪の厚み、垂れた毛束、装飾を区別する。`hair-back`という名前や後方のzSortだけで、そのPart内のすべての画素を後向きの面と判断しない。

| ケース | 深度・運動の担当 | 追加で読むもの |
|---|---|---|
| 一般的な後頭部、短髪、まとめ髪 | 顔から頭頂・後頭・うなじへ続く頭部と、その上の髪の厚み。まず頭部運動に追従 | 下記の共通手順と[頭皮・内部模様のPart手順](../../nijigenerate-post-rig-adjustment/references/head-hair-surface-correction.md) |
| 長髪 | 頭皮に付く上部と、首・肩より下へ垂れる部分を分けて扱う | [長髪の追従](../../nijigenerate-depth-skeleton-setup/references/long-hair-follow.md)と[Ao全項目の参照表](../../nijigenerate-post-rig-adjustment/references/ao-head-long-hair-examples.md)。各項目の適用／不適用理由を記録 |
| 髪がない、剃髪、皮膚の頭皮が見える | 髪の体積ではなく、露出した頭皮と後頭部の皮膚面 | 下記の髪なし手順。髪ソース・毛束物理のみ対象外 |
| 帽子などで覆われる | 覆いと頭皮の支持面を分離。隠れた支持関係も維持 | 頭部共通検査と装飾の接続。隠蔽は深度不良の修正ではない |

## 共通手順：一つの頭部として成立させる

1. 同じ投影・尺度で中立、左右Yaw、前後Pitch、四隅と中間値を取得する。顔・前髪・耳後ろ・後ろ髪・首を同時に見る。顔だけの切り抜きで後頭部を判定しない。
2. 重なった素材に同じ頭皮が描かれていないか、UV上の模様・頭頂・分け目を対応付ける。Aoでは前髪側と`hair-ear-back`側の重複頭皮が別の深度で動いていた。別Partでも同じ面を表す箇所は、実効深度と動きが整合しなければならない。
3. 複数の頭頂に見える原因を、面の深度、Head/Bodyの追従、Partの残差、欠けた素材に分類する。受け入れ済みの顔や首を移して、後頭部のずれを隠さない。
4. 深度不良はこのスキルで明示的に修正する。後頭部中央の後方への厚み、頭頂の縁、うなじへの接続を別々に判断する。Aoの「後頭部全体を手前へ動かす」試行は丸みを失わせた。球・楕円・Sinなどの一律式や一括オフセットを、絵からの局所判断の代わりにしない。正常な外周・下側の髪・隣接面を保つ。
5. 生成参照の角度と部位の妥当性を確認する。参照にも別の後頭部が付いたような形があれば、その領域は棄却する。Aoの生成後ろ髪は実際に棄却された。参照との類似だけを合格条件にしない。
6. 深度修正後に残る頭皮の継ぎ目や内部模様は、[Part手順](../../nijigenerate-post-rig-adjustment/references/head-hair-surface-correction.md)へ渡す。深度・骨の問題と、外周を保った内部模様の問題を混同しない。
7. 既存リグでは現在の手動補正を保護し、影響する再計算と読戻し差分を限定する。Aoの局所修正は全体Fit Zや標準パラメータ再生成を行わなかった。初期リグのFit Z順序と混同せず、必要なZ整合の検査は[深度状態の検査](depth-state-verification.md)に従う。

## 髪がない場合

1. 額から頭頂、側頭、後頭部中央、うなじまでの皮膚の連続を確認する。耳と首の接点も含める。毛髪の厚みや毛先の輪郭を加えない。
2. 顔と頭皮が同一Partなら、その中の正面・側面・後面を区別する。分かれたPartなら重複面と接合帯を対応付ける。髪用Gridや独立した垂れ髪ボーンを作ることを前提にしない。
3. 頭皮の模様・ハイライトは、その見えている面の向きに従う。Aoの前髪を使う内部模様補正は、前髪がないモデルの既定手法ではない。同じキャラクターの皮膚面と同姿勢の参照から必要な残差を判断する。
4. 横・上下向きで新たに見える皮膚が素材に存在しない場合、透明な領域を引き伸ばして埋めない。欠けた素材として記録し、許可された素材準備へ渡す。描かれていない後面を見えたことにしない。
5. Headの運動、首との接続、耳との重なりを評価する。後頭部そのものに垂れ髪用のBody追従や振り子物理を割り当てない。髪なしの検証済み作例は本パッケージにはなく、Aoの画像をその実証として扱わない。

## 完了に必要な証拠

頭頂が一つであること、側頭から耳・うなじへの接続、後頭部の厚み、前髪等との継ぎ目、外周と内部模様の整合を別項目として記録する。実際に使用する全Faceキーと、Face/Bodyが反対方向を向く姿勢・Rollを含む複合姿勢を確認する。5×5なら25キーを検査するが、Aoのキー数を別モデルへ強制しない。深度段階で保留したPart残差は担当と終了条件を付け、頭部の最終検査で閉じる。
