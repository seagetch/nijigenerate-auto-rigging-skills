## 深度の座標と合成

現在の独立したnijigenerate実装 `commands/depth/bone.d` と
`viewport/depth/common/targetview.d` の定義に合わせ、DepthRigRootが実際に参照している
全対象のroot-space XY範囲から `max(1, max(extent_x, extent_y) * 0.42 / 2.9)` を求める。
対象ごとのbboxから別々の深度単位を作らない。

各active BoneSourceについて、`raw_depth * depthScale + depthOffset` を深度単位へ変換し、
ノードの変換を合成した上で宿主骨のZ原点との差を求める。
同じ面でactive sourceの深度変換が異なる場合、1本の場に潰さず未対応として拒否する。
現在採取した参照では、複数active sourceがある面でもその面内の深度変換は一致している。

頭部は顔グリッド幅、胴体・衣装等はPelvis–Neck距離で無次元化する。

Source側のscaleは測定起伏に合成済みであるため、適用側で二重に掛けない。

共通グリッドは対応する線の順位を使って適合し、最も細かい参照の線数を保持する。
2つの軸配列を単純に結合して極端に狭いセルを作らない。
