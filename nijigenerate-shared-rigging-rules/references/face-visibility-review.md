# 頬の造形と、頬を隠しているものを分けて検証する

顔の深度・輪郭を評価する前と、関連する素材・変形・描画設定を変えた後に使う。汎用の要件は横髪を編集することではなく、誤った素材や遮蔽が頬の正しい描画と評価を妨げていないことを確認することである。生成・自動処理・過去の補正で作られた素材も、正しいという前提を置かない。

## 1. 何が見えるべきかを元絵と参照から決める

- 中立、両Yaw、両Pitch、四隅について、手前の目尻横、頬の張り、顎への移行、奥側の消える境界を対応付ける。
- 領域を「完成表示で見えるべき」「デザインとして髪などに隠れる」「現在は遮蔽され評価できない」に分け、どのPart／素材が覆うかを記録する。元絵にある意図的な髪の重なりと、生成物が追加した余計な毛束・不透明画素を区別する。
- 髪で隠れているため不自然な頬が見えない状態を、顔が正しくなった証拠にしない。逆に、頬を全部見せるため意図的な重なりを削ることも目標にしない。

## 2. 同じ姿勢で顔そのものと完成表示を切り分ける

1. カメラと全パラメータを固定し、物理や他のアニメーションによる差がないことを確認する。通常表示を保存する。
2. 頬を覆うPartだけを一時的に非表示／半透明化する、または色分けして、顔のテクスチャとメッシュ、覆っている境界を特定する。顔の補正値を変えずに比較する。重なった複数の髪は必要なものから一つずつ切り分け、名前だけで責任Partを決めない。
3. 分離表示では顔の目尻〜頬〜顎の連続性と深度の立体を評価する。通常表示では、その正しい形が意図した範囲で見え、参照と同じ隠れ方をしているかを評価する。分離表示だけを完成画像や合格証拠として提出しない。
4. 一時的な表示・色・不透明度をすべて復元し、値と通常描画を読み戻す。分離しても判断できない箇所は未検証として残し、補助線や数値だけで合格に置き換えない。

## 3. 誤りの所有箇所を決める

| 観察 | 確認・修正する箇所 |
|---|---|
| 遮蔽物を除いても頬が不自然 | 顔の深度、親寄与、手前側のPart輪郭。髪を増やして隠さない。 |
| 頬自体は妥当だが通常表示で必要な輪郭が消える | 覆うPartの素材alpha／描かれた内容、UV・メッシュ被覆、深度、変形、マスク、実際の描画順。顔を動かして逃がさない。 |
| 元素材では見えていた頬が生成素材で隠れる | 生成による余計な描画・alpha・形状・登録ずれを元素材と比較。確認できた素材欠陥だけを修正し、リグで相殺しない。 |
| 元の重なりが失われ、横髪が外側・奥側に見える | 素材の削り過ぎ、輪郭変更、登録、変形、描画順を切り分ける。zSort値の一致だけで正常と断定しない。 |
| 遠側だけの消え方がおかしい | 顔と遮蔽物の深度・投影・遮蔽を確認。隠れるべき奥側をPart XYで引き出さない。 |

静的zSortだけ、総不透明面積だけ、生成時の指示文だけでは原因を確定できない。変更前後の元素材・合成表示・分離表示の対応で判断する。原因がテクスチャにあると確認できたときだけ、その欠陥と許可範囲に応じて素材修正へ進む。「横髪がある」ことは再生成の理由にならない。

## 4. 合格と再検査

各方向について、(a) 分離して確認した頬の造形、(b) 通常表示での意図した見え方、(c) 元絵に対する遮蔽物の妥当性を別々に記録する。必要な輪郭が誤った素材に隠れている場合は顔の工程を完了にしない。素材・深度・描画順・変形を変更したら、この3点を同じ方向表で再検査する。

今回の横髪の再生成失敗は[個別事例](texture-cleanup-preserve-shape.md)であり、汎用的な横髪編集処方ではない。一般化するのは、生成物を含む遮蔽物の誤りを検出し、顔の造形の誤りと混同しない検証手順である。
