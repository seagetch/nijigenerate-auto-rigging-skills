# 各向きの参照生成 → 深度 → 個別Part補正

顔・胴体などを各角度の参照画像に合わせる依頼で使う横断手順。画像生成の依頼・承認は既存会話を引き継ぎ、同じ承認を取り直さない。生成が許可されていなければ既存の適切な参照を使う。この手順は参照絵の生成であり、深度画像の再生成・モデルの再読み込み・リグの作り直しを許可するものではない。

担当は、参照生成に`imagegen`、深度値に`nijigenerate-depth-import-adjustment`、骨の誤りに`nijigenerate-depth-skeleton-setup`、個別Part残差に`nijigenerate-post-rig-adjustment`。一つの比較台帳を各担当で引き継ぐ。

## 1. 方向表と変更前の記録

- 対象領域と、親／隣接パーツを含む範囲を決める。顔なら頭蓋・髪・耳・首、胴体なら首・襟・肩・腕・袖・胸・腰・スカートまで接続を確認できるようにする。
- 対象パラメータの実際の軸・範囲・中立値と動きを読む。基本の比較は中立、左右、上下、四隅の9方向。既存キーに合わせ、報告された中間値・混合姿勢も方向表へ追加する。9方向の参照は5×5の全キー検査の代わりにならない。
- Face Pitchの+は上向き、Body Pitchの+は後傾。Yawの符号と画面側／キャラクター側の対応は現モデルで確認する。パラメータ値±1を回転±30度などと決めつけない。
- 方向ごとにFace/BodyのYaw-PitchとRoll、関連リンク・表情、物理の停止／リセット状態、カメラ・投影・倍率・クロップを記録する。隠れた別パラメータの変化を角度差として扱わない。
- 現モデルを同一条件で撮影する。原寸全体と対象領域の画像、数値状態、既存の深度・骨・Part補正を保存する。自動生成・Fit Zを繰り返して比較状態を作らない。

## 2. 各向きの参照を生成する

1. `imagegen`の手順で、元絵（造形・衣装の基準）と、その角度のモデル撮影（向き・ポーズ・構図の基準）を同時に渡す。必要なら全身と部位の切り出しを併用する。別角度の生成画像だけを次の角度の基準にして、元絵から徐々に離れないようにする。
2. 一方向ごとに、元絵の同一性・体格・衣装・装飾の左右を保つこと、角度基準の頭／胸郭／骨盤の向き、カメラと姿勢を保つことを指定する。左右の取り違えが起きやすい場合は、画面手前／奥の肩・頬と中心線の位置も言語化する。
3. 欠けている自然な立体表現を具体的に指定する。顔は頬・顎・鼻・額と頭蓋の関係、胴体は胸郭の厚み・側面・肩から脇と腰の連続性。モデルの平たい歪みをそのまま模写するよう指示しない。
4. 生成結果、実際に渡した入力画像、プロンプト、方向IDを保存する。単一の参考絵から他の向きの形状を推測して「各向き生成済み」と書かない。既存の中立元絵を使った方向はその旨を記録する。

プロンプトの構成例（値は現在の方向表から埋める）：

> 画像Aをキャラクター・衣装・体格の基準、画像Bを今回の向き・ポーズ・カメラの基準とする。［対象部位］を、画像Bと同じ［確認済みの方向／手前と奥］で描く。［保持するランドマークと左右非対称の装飾］を維持し、［不足している厚み・輪郭・接続］を自然にする。元絵の体格、衣装範囲、隣接部位を保ち、切断、別のポーズ、装飾の追加をしない。

これは指定方法の例であり、生成物の正しさを保証しない。人体としての自然さと元絵の同一性を次の段階で別々に検査する。

## 3. 参照の角度・同一性を検査する

- 各生成候補を、対応するモデル撮影と元絵の両方に照合する。鼻／顔中心線、耳の前後、肩・胸骨・腰の位置、近側／遠側の見え方から向きと投影を確認する。
- 比較用に共通の投影・倍率・位置を合わせる。必要な登録は画像全体の平行移動と一様拡大縮小にとどめ、顔幅や胸だけを個別に伸ばして一致させない。姿勢や透視が違う場合は再生成・参照選び直しに戻る。
- 各候補を「使用可能な領域」「不採用の領域」「角度未確認」に分ける。例えば顔の輪郭が使えても、後ろ髪や耳まで正しいとは限らない。生成候補の胸の増量や衣装変更を、そのままモデルへ移さない。
- 方向表に採用した参照と除外理由を対応付ける。必須方向の参照が使えない間は、その方向を一致済みとしない。

[顔・胴体の実際の比較資料](../../nijigenerate-post-rig-adjustment/references/ao-visual-examples.md)も参照する。収録画像は履歴上の候補・不具合例で、無条件の正解ではない。

## 4. 最初に深度で基礎形状を合わせる

1. 全方向を並べ、共通して不足する立体を見極める。一枚だけ良くなる奥行き変更で反対方向を壊さない。必要な厚み、断面の高さによる違い、近側／遠側、前面／側面／背面を元絵と参照から判断する。
2. 顔は額・鼻・頬・顎と頭蓋の厚み、胴体は上部から腰までの断面変化、胸郭と局所胸部の分担、肩・腕・袖の丸み、腰と衣装の連続性を確認する。正面シルエットを保ったまま、横・斜上・斜下で平板に見えないことを調べる。
3. 深度担当手順で現在のGridサンプルと部位を対応付け、必要な深度値を直接検討して設定する。参照画像の明るさから深度を自動推定したり、sin・楕円など一律の式で人体断面を置き換えたりしない。座標変換・記録・数値検証の補助と、造形の判断を区別する。
4. 初期構築では深度→Fit Z→標準パラメータ生成の順を守る。既存リグ修正では初期構築を再実行しない。必要な更新のみを、[状態分離手順](parameter-state-isolation.md)と深度担当手順に従って行い、既存骨・手動キーへの再計算の波及を読み戻す。
5. 同じ方向表・参照で深度調整後を撮り直す。角度ごとの基礎厚みと接続を検査する。基礎形状は深度で改善し、深度では表現できない露出面・輪郭・遮蔽の残差を部位とキーごとに分けて記録する。

この段階の合格は基礎立体に対するもの。個別輪郭・オクルージョンの残りはPart段階へ明示的に引き継げるが、平板な胴体や不正な骨の動きをPartで隠すために通過させない。

## 5. 深度だけで表現できない差を個別Partで合わせる

1. 深度調整後の現在の合成結果を出発点とし、変更前の親を前提にした古い補正値を重ねない。骨の回転と深度による大まかな動きは維持する。
2. 参照の輪郭・内部ランドマーク・露出面・隠れる境界をO/T/Nで対応付け、[個別Part手順](../../nijigenerate-post-rig-adjustment/references/individual-2p5d-and-reference.md)へ渡す。顔の顎・頬・鼻、胴体の横面、肩・脇・襟など、残差が属するPartの頂点と周辺だけを調整する。
3. 顔は耳の露出より滑らかな輪郭を優先し、奥側の頬を削りすぎず、顎を尖らせすぎない。胴体は胸を腕へ引っ張って穴を埋めず、胸郭側面と脇の独立した面を保つ。全体の姿勢回転を別のPart変形で再実装しない。
4. 欠けた塗り面は許可された素材修正へ、接合帯の問題は片側基準のWeldingへ分ける。全脇を溶接したり、表示順を変えて形の破綻を隠したりしない。Grid XY編集を個別Part作業の前提にしない。
5. 一方向の補正後にも、反対方向・隣の半値・関連する混合姿勢を確認する。最後に同じ比較台帳の全方向を再検査する。

## 6. 同じ参照で最終照合する

各方向を「変更前／採用参照／深度調整後／Part補正後」の同倍率で示す。局所の拡大と隣接部位を含む全体を併記する。輪郭だけでなく、鼻などの内部位置、肩と胸郭の接続、遠側の面、隠れる境界も比較する。数値差分やコンタクトシートの存在だけを一致の証明にしない。

比較台帳の最小項目：方向ID、全パラメータ値、カメラ・物理状態、元撮影、生成入力とプロンプト、採用参照と除外領域、深度変更とその結果、Part残差とその結果、比較画像、判定と未解決項目。既存の5×5キーなら全25セルの補間状態も確認し、報告された混合姿勢を省略しない。

チェックポイントは[共通の工程別判定](scope-and-checkpoints.md)に従う。深度段階でPart固有の残差を保留にできても、最終段階でその保留を残したまま全体一致・完了とは言わない。
