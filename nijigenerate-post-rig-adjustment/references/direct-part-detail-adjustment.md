# Part直接補正

## 適用条件

親GridDeformerまたはPathDeformerの大域変形が正しく、問題が一つのPart内の小さな輪郭・継ぎ目・厚み表現へ限定された後にだけ適用する。

次の問題はPart直接補正に適する。

- 頬や口角など、少数頂点のシルエット。
- 袖口、襟、裾、髪先、装飾品の局所的な継ぎ目。
- 特定キーだけで発生する小さな浮き、隙間、重なり。
- 親Gridを動かすと正常な周辺Partまで崩れる問題。

面全体の向き、深度、骨追従、複数Partの共通移動はPartで直さない。

## 頂点選択

1. 問題キーを正確に設定する。
2. 対象Part UUID、メッシュ頂点順、現在の`deform`配列を読む。
3. 問題の中心頂点と、補正を減衰させる隣接頂点を特定する。
4. キャラクター左右、画面左右、パラメータ符号を記録する。
5. 対象外の輪郭、中心線、アンカーを固定する。

「頬」「側面」「裾」のような名称だけで頂点を推測しない。現在画像と実メッシュの対応を使う。

## 減衰補正

中心頂点へ最大差分を与え、隣接頂点へ連続的に弱い差分を与える。1頂点だけを大きく動かして尖りや折れを作らない。

概念例：

```text
中心:       correction * 1.00
隣接1列目: correction * 0.50
隣接2列目: correction * 0.15
範囲外:     0
```

倍率は固定値ではない。メッシュ密度、輪郭、画像上の問題範囲から決める。

既存Partバインディングがある場合は、それを保持して差分を加える。配列を新規のゼロ配列で置き換えない。

## 中立と対称

- 中立キーの直接補正は原則ゼロにする。
- 左右対称の問題でも、画像と既存バインディングが非対称なら機械的にミラーしない。
- 片側だけの補正が対角キーで反対側へ漏れないことを確認する。
- 同じPartが複数パラメータに結び付く場合、合成時の過剰移動を確認する。

## Part補正にしないもの

- 口や顔全体が前へ出すぎる：深度または親Gridの問題。
- 髪やHeadwear全体が顔を貫通する：深度または親Gridの問題。
- 腕・脚全体が関節から外れる：骨、BoneSource、親Grid／Pathの問題。
- 後方部品が前景の外へはみ出すだけ：Mask候補。
- 揺れが不足する：Physics候補。

## 完了条件

- 問題が対象キーで解消する。
- 隣接キーに折れ、震え、反転がない。
- 中立と非対象パラメータが変わらない。
- 対象Part以外へバインディングが追加されていない。

## 角度固有の可視面と参照比較

2.5Dの可視面・輪郭は [individual-2p5d-and-reference.md](individual-2p5d-and-reference.md) を使う。親が正しいとは、今回の課題が要求する骨運動と基礎深度が成立していることを指し、先にGridを変更したことを意味しない。肩の接合は [one-sided-welding.md](one-sided-welding.md)、カラーと胸襟の分離は [collar-and-neck-surfaces.md](collar-and-neck-surfaces.md) へ進む。
