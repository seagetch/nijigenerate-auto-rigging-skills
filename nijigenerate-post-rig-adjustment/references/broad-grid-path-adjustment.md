# GridDeformer・PathDeformerによる広域補正

## 基本原則

標準Depthパラメータが生成した既存バインディングを読み、その値へ小さな補正差分を加える。独自の投影式でキー全体を再生成しない。

この手順はGrid XY補正が許され、原因が既存Gridバインディングにある場合だけ使う。広い領域という理由だけではGridを選ばない。厚みは深度、姿勢は骨、角度ごとの輪郭・可視面残差は個別Partへ分類する。PathDeformerは、現在のモデルに意図的に残されている曲線状の手足、尾、紐、リボン、毛束などだけに使用する。GridDeformerへ置換済みの部位へPathDeformerを再作成しない。

## GridDeformerを直す条件

- 複数の子Partが同じ破綻を示す。
- 面全体の回り込み、縮み、伸び、傾きが不自然である。
- 子Partを個別に直すと継ぎ目が裂ける。
- Face、Body、Chest、髪、衣装の広い領域が一枚板のように動く。
- 親Gridの補正で複数の局所問題を同時に解消できる。

既存のキー値を読み、対象キーの既存`deform`値を基準にする。変更する頂点は問題領域から周囲へ滑らかに減衰させる。中心線、アンカー、左右対称、親子の接続点を固定すべきか先に決める。

## PathDeformerを直す条件

- 根元・中間・先端の連続した曲げで表現すべき部位である。
- 根元を親へ固定しながら中間を曲げる必要がある。
- 足を接地させる場合、足側の終端をゼロへ減衰させる必要がある。
- 遠側の腕などを肩から回し、肘・手へ追従量を配分する必要がある。

現在の階層にPathDeformerがない場合は、後調整だけを理由に新設しない。構造変更が必要なら`nijigenerate-model-setup`または該当するルート位置スキルへ戻す。

## 補正値の扱い

概念上は次のように既存値へ加算する。

```text
adjusted_deform = generated_deform + reviewed_correction
```

`generated_deform`をゼロ扱いしない。対象ノード、頂点順、配列長、パラメータ値が一致しない場合は停止する。

## キー間の連続性

問題キーだけでなく、次を必ず比較する。

- 中立キー
- 同軸の隣接キー
- 反対側キー
- Yaw・Pitchの対角キー
- Rollや口・目など同時使用される主要パラメータ

一つの端点だけを直して中間キーに折れや反転を作らない。自動補間に任せられない場合だけ中間キーを補正する。

## 広域補正の終了条件

- 親子とアンカーが外れない。
- 複数Partの相対位置が一貫している。
- 中立が変わらない。
- 反対側と対角キーで新しい破綻がない。
- 残った問題を具体的なPartと頂点へ限定できる。
