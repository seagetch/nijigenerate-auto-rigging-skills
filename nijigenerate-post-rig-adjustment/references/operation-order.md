# 後調整の工程順

## 入口条件

次の状態がすべて成立してから開始する。

1. `DepthRigRoot`と標準DepthBoneが存在する。
2. DepthBoneの位置、`LockToRoot`の足、GridDeformerのBoneSourceが検証済みである。
3. PSD深度の取り込みとGridDeformerの局所深度補正が完了している。
4. 最後の深度補正後に`Fit Z to Depth`が実行され、数値で確認されている。
5. Fit Zの後に標準Depthパラメータが生成されている。
6. 生成されたFace、Body、Rollなどのパラメータとバインディングをnjcで読み戻せる。

条件を満たさない場合は後調整を開始しない。深度問題は`nijigenerate-depth-import-adjustment`、骨・BoneSource問題は`nijigenerate-depth-skeleton-setup`へ戻す。

## 問題の分類

| 観察結果 | 修正先 |
|---|---|
| 中立時から前後関係、厚み、凹凸が不正 | 深度情報工程へ戻す |
| 部位全体が骨から外れる、左右骨や足の追従が不正 | DepthSkeleton工程へ戻す |
| 複数Partが同じ方向へ不自然に動く | 深度・骨・親寄与を診断し、許された責任層だけ直す |
| 曲線状の手足・紐・尾などの根元から先端までが不自然 | 意図的に存在するPathDeformerを直す |
| 広域変形は正しいが一部の輪郭、継ぎ目、口角などだけ不正 | Partを直接補正する |
| 後方部品が前景を突き抜けるだけ | Occlusion Maskを検討する |
| 揺れや遅延追従が必要 | SimplePhysicsへ送る |

## 実行順

1. njcで現在のツール一覧と該当コマンドのschemaを確認する。
2. 対象パラメータの正確な値、既存キー、対象ノード、既存バインディングを記録する。
3. 中立、問題キー、左右対称キー、隣接キー、必要な対角キーを保存する。
4. 全体の問題一覧を保ったまま今回の変更を一つに絞り、深度／骨／Grid／Path／Partの責任を決める。
5. 大域運動に欠陥がある場合だけ、その責任層を許可範囲で直す。正しい親には変更を加えずPart残差へ進む。
6. 同じ画像群で大域運動が正しく保たれていることを確認する。Grid直接補正禁止を工程順で上書きしない。
7. 残った局所問題だけをPartへ直接追加する。
8. 対角キーと複合パラメータで破綻が増えていないことを確認する。
9. 中立へ戻し、変更対象と非変更対象を読み戻す。
10. 明示した保存先へnjcで保存する。

標準生成結果をゼロから置き換えない。既存バインディングを基準に、必要な差分だけを加える。
