# 頭皮の継ぎ目と、外周を保った髪内部の2.5D補正

先に[後頭部の共通評価](../../nijigenerate-depth-import-adjustment/references/head-volume-and-hair-cases.md)で、基礎深度と骨運動の担当を確定する。後頭部は頭部リグの必須検査対象。既に正しい深度・骨・外周を、このPart作業のために変えない。

## 1. 同じ頭皮を描くPart間の継ぎ目

1. 現在のメッシュ・UV・全キーを読取り、前髪、耳後ろの髪、後ろ髪で重なる頭皮の画素を対応付ける。ノードの矩形中心ではなく、分け目・模様・輪郭などの同じ位置を使う。
2. 深度修正後の合成済み表示で、各姿勢の対応点を同じ局所座標O/T/Nに置く。中立に元々ある重なり幅を保持し、すべてを一点へ潰さない。
3. その姿勢で残るずれだけを、原因を持つPartの接合領域へ加える。左右や上下の補正を単純に反転コピーしない。修正対象外の耳・うなじ・下側の毛束に向かって補正を滑らかに0へ落とす。
4. 上流の深度や骨が後で変わったら、子の補正を現在の合成結果から再評価する。古い残差を足し続けない。輪郭・模様・隣接Partを同時に確認する。

## 2. 外周は正しいが内部模様が奥側に張り付いて見える

1. ユーザーが受け入れた外周と、その周囲の支持三角形を保護対象にする。透明パディングの矩形ではなく、絵のalpha境界に触れる三角形、根元、耳・装飾との接点、下側の髪を特定する。
2. 見える模様がどの面を表すかを決める。後ろ髪Partにも手前側に凸となる頭頂の模様が含まれ得る。Part名や背面の深度だけを内部模様の向きの根拠にしない。
3. Aoでは、既に成立していた前髪の凸面運動を各Face姿勢で観測し、内部模様の運動の参照にした。実際の対応面がある場合にだけ使い、前髪の変形値をそのまま別Partへコピーしない。別モデルでは同姿勢の参照や有効な対応面を選ぶ。独立した投影式で全方向を作らない。
4. 内部の毛流れ・分け目・明暗境界から目標を置き、現在の合成済み運動との差をPart残差にする。外周・接点は0、内部は滑らかな支持領域、下側へ0に移行させる。少数頂点へ大きな移動を集中させると毛流れが角張る。Aoの8頂点の試行はこの理由で棄却された。
5. メッシュ不足が確認された場合だけ、[依存付きメッシュ変更](../../nijigenerate-automesh-setup/references/parameter-only-and-rigged-mesh.md)へ進む。Aoでは上側の既存辺を局所分割し、元の頂点を保持、新頂点のUVと各キーの表示位置を元の三角形の重心座標で継承した。この補間は既存面を保持するための処理であり、深度や頭の形を数式で作る操作ではない。
6. 新頂点が親Gridから受けるサンプリング差を確認する。まず全キーで変更前の三角形面と同じ表示位置になるよう差を補償し、それから内部模様の残差を加える。中立だけの一致では不十分。既存頂点順・UV・バインディング・Welding等の依存を保証できる前に適用しない。
7. 各方向で新しい三角形反転、潰れ、模様の折れがないかを確認し、必要ならその姿勢の残差量を抑える。中間キーが端点以上に膨らまないことも検査する。外周保持を崩して内部を合わせない。

## 3. 必須の読戻しと見た目の検査

- 現在の全Faceキーを比較する。Aoの記録は25キー、24個の非中立残差と0の中立だった。
- 中立、外周と境界三角形、下側毛束、前髪・耳後ろ・顔・首の位置を別々に比較する。頂点一致に加え、alpha輪郭と模様を画像で見る。
- FaceとBodyを逆向きにした姿勢、前後傾、Face/BodyのRollも検査する。頭皮上部と体駆動の下側毛束を一緒に確認する。
- 骨、BoneSource、深度、node Z、zSort、既存キー、マスク、物理を保護し、意図したメッシュとPart残差以外の差を説明する。

[Aoの比較画像・数値記録](ao-head-long-hair-examples.md)は手順を読む作例であり、現在のモデルの合格証拠ではない。髪がないモデルでは毛流れ補正は対象外だが、頭皮の継ぎ目と内部の皮膚模様の検査は残る。
